# Recovery-Optimized Calisthenics Plan (CA Final Phase)

## Goals

-   Maximize study performance
-   Lose body fat
-   Maintain/build strength
-   Increase pull-ups
-   Recover well after every session

## Training Principles

-   Never train to failure.
-   Leave **1 rep in reserve (1 RIR)** on pull-ups.
-   Finish every workout feeling like you could do a little more.
-   Sessions should last **35--40 minutes**.

------------------------------------------------------------------------

# Monday -- Pull

## Warm-up (2 minutes)

-   Arm circles ×10 each direction
-   Dead hang ×20 seconds
-   Scapular pull-ups ×3

Rest 60--90 seconds.

## Main Workout

  Exercise                Sets                    Reps
  --------------------- ------ -----------------------
  Pull-ups                   5                       2
  Negative Pull-ups          2   3 (6--8 sec lowering)
  Band Rows                  3                  10--12
  Hanging Knee Raises        3                   8--10

------------------------------------------------------------------------

# Recovery Rules

-   Never train to failure.
-   If the warm-up makes your muscles tired, reduce it further.
-   If study performance drops after training, remove one set from each
    exercise the following week.
-   Every 4th week, reduce all sets by about 40--50% (deload week).
